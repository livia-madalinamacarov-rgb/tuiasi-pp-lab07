     In aceasta problema am realizat un program care proceseaza ultimele 50 de intrari dintr-un fisier de tip log (history.log). Fiecare intrare din fisier are mai multe campuri, precum Start-Date, Commandline, Requested-By, actiunea efectuata si End-Date, dar in aceasta problema se folosesc doar campurile Start-Date si Commandline. Programul citeste fisierul si il imparte in mai multe blocuri, fiecare reprezentand o intrare. Din acestea sunt luate ultimele 50. Pentru fiecare intrare se extrage data de inceput si comanda. Data este convertita intr-un timestamp (LocalDateTime), iar impreuna cu comanda este salvata intr-un obiect de tip HistoryLogRecord. Pentru a lucra mai usor cu datele, se defineste clasa HistoryLogRecord care contine doua campuri: timestamp (LocalDateTime) si command (String). Clasa implementeaza Comparable, astfel incat obiectele pot fi comparate intre ele dupa timp, pentru a vedea care este mai recent. Toate obiectele create sunt stocate intr-un MutableHashMap, unde cheia este timestamp-ul, iar valoarea este obiectul HistoryLogRecord corespunzator. Functia max este o functie generica care primeste doua obiecte si il returneaza pe cel mai mare. In cazul asta, returneaza obiectul cu timestamp mai recent. Functia searchAndReplace are rolul de a cauta un obiect intr-un map si de a-l inlocui cu altul. Map-ul are forma <timestamp, HistoryLogRecord>. Functia parcurge toate perechile cheie-valoare din map si verifica daca valoarea este egala cu obiectul cautat. Daca il gaseste, retine cheia si apoi inlocuieste valoarea cu cea noua.Functia parseHistoryLog citeste fisierul folosind File(path).readText(), apoi imparte continutul in blocuri folosind split("\n\n"), deoarece fiecare intrare este separata printr-o linie goala. Pentru fiecare bloc, se extragliniile si se cauta linia care incepe cu Start-Date si cea care incepe cu Commandline. Daca ambele exista, se extrag valorile, se transforma data din String in LocalDateTime folosind DateTimeFormatter, apoi se creeaza un obiect HistoryLogRecord. Acest obiect este adaugat intr-un map, unde cheia este timestamp-ul, iar valoarea este obiectul. In functia main se apeleaza parseHistoryLog pentru a obtine map-ul si se afiseaza toate inregistrarile. Valorile sunt transformate intr-o lista pentru a putea fi accesate usor. Daca exista cel putin doua elemente, se calculeaza maximul dintre primele doua si se testeaza functia searchAndReplace, afisand valorile inainte si dupa inlocuire.
